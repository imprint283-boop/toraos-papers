# Zenodo情報の準備

[root .zenodo.json](../.zenodo.json) に文書集の登録情報を用意しました。[metadata.candidate.json](metadata.candidate.json) は同一内容の確認用コピーです。文章のライセンスは本人が決定した`cc-by-4.0`を明記しています。P1の著者は中川 翼、日付は2026-08-30に確定し、確認対象の公開範囲も本人が決定済みです。文書集の登録区分はpublication/otherです。

ファイルの準備はZenodoへの登録や公開ではありません。翼さんの「出す」の指示まで、リポジトリ公開、リリース作成、Zenodo操作は行いません。公開許可後に実際の公開日などを確定し、GitHub連携とリリースの工程へ進みます。CITATION.cffとroot `.zenodo.json`の両方がある場合、Zenodoは `.zenodo.json`だけを読み、CITATION.cffを無視します。[公式説明](https://help.zenodo.org/docs/github/describe-software/zenodo-json/)

ライセンスは必須です。既定値に任せず、本人が選んだCC BY 4.0を情報ファイルに明記しました。[公式説明](https://help.zenodo.org/docs/deposit/describe-records/licenses/)

まだ公開日・公開版・DOIを設定していません。論文の執筆日を文書集の公開日へ転記しません。Zenodoへのログイン、連携設定、登録、DOI予約は行っていません。
